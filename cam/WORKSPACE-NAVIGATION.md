# NASAQ workspace navigation

The main player owns the music library, playlists and track ordering. Its menu bar also opens six task-specific workspace sections directly:

| Section | Responsibilities |
| --- | --- |
| Live audio | Arm microphone, hold to talk, stop audio |
| Announcements | Announcement studio, text-to-speech voice, optional chimes |
| Schedule | Review events, schedule an occurrence, cancel a pending event |
| Prayer times | City, external timetable source, pauses and optional adhan |
| Records & reports | Music-rights records and documents, CSV/PDF playback exports |
| Settings | NASAQ activation status, language, operator PIN/lock, updates |

The workspace sidebar changes the visible page without creating additional workspace windows. Arabic uses right-to-left layout; English uses left-to-right layout. Navigation releases microphone paging. Existing dialogs retain their operator-lock checks, and the scheduler continues to run while the workspace is hidden.

Application activation is distinct from music-rights documentation. Activation status appears only in Settings; the activation-required dialog may still open automatically when necessary. Compliance Lite records are not regulatory certification.

The review suite exercises all six destinations, verifies that microphone controls, the event table and activation status appear only on their respective pages, and captures both language layouts. Audio and activation regression suites remain separate.
