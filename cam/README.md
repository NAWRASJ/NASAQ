# نسق NASAQ

**إدارة الصوت التجاري — Commercial Audio Manager**

الإصدار الهندسي 0.2.1. الاسم المعتمد هو «نسق NASAQ»، والشعار ثلاثة شرائط عمودية فيروزية توحي بحرف n، بطرفين طويلين وشريط أوسط قصير مرتفع، على خلفية كحلية.

شغّل `NASAQ.exe` من مجلد الحزمة كاملًا، أو استخدم مثبت `NASAQ-0.2.1-setup.exe`. افتح قائمة «نسق NASAQ / إدارة الصوت» للوصول إلى الموسيقى والجدولة والأذان والإعلانات والميكروفون وسجلات التشغيل.

هذه نسخة مشتقة ومعدلة من Strawberry وليست إصدارًا رسميًا منه. تستخدم مكتبة الموسيقى ومحركه داخل العملية نفسها. تعرض صفحة «حول البرنامج» هوية نسق مع نسب الحقوق والمساهمات الأصلية. الشيفرة GPL-3.0-or-later، والنص الكامل في COPYING.

الملفات غير موقعة حاليًا؛ تغيير الاسم والشعار لا يعالج حظر Smart App Control. أبقِ حماية Windows مفعلة. تعليمات التوقيع في docs/SIGNING.md ونتيجة هذه النسخة في docs/BRANDING-REPORT.txt.

للحفاظ على البيانات، بقيت معرفات التخزين الداخلية `CAMProject` و`CAM-Strawberry` و`cam.sqlite` كما كانت. لم تُنقل أو تُحذف قواعد البيانات. أسماء `CAM_SMOKE_OUTPUT` و`CAM_TEST_WAV` داخل أدوات الاختبار تقنية وليست اسم المنتج.

المزايا الموجودة: قوائم موسيقى، جدولة مرة واحدة، استيراد جدول صلاة مع أذان اختياري، أصوات SAPI المثبتة، أولوية للميكروفون والإعلانات، PIN محلي، سجل ترخيص موسيقى وتذكير تجديد وسجلات CSV/PDF. سجل الترخيص لا يمنح حقوق تشغيل الموسيقى ولا يمثل اعتمادًا تنظيميًا.

المتبقي من V1: التكرار وتحرير المواعيد، الحساب التلقائي للصلاة، SILMA والسحابة، التفعيل الفعلي والعمل دون اتصال، تقوية الاستعادة، واختبارات الأجهزة والتثبيت بعد التوقيع. Teletext مؤجل.

تحديثات نسق تتم عبر زر Updates في أدوات نسق ومستودع GitHub الذي يحدده المسؤول. أزيل مسار عرض تحديثات Strawberry الأصلية داخل المنتج المعدل حتى لا يستبدل نسخة نسق بمنتج مختلف. مستودع المشروع الذي أنشأه المالك: https://github.com/NAWRASJ/NASAQ . أدخل NAWRASJ/NASAQ عند استخدام Updates. ربط المستودع لا يعني توفر إصدار منشور بعد.

ملفات الهوية الأصلية SVG وPNG وICO في branding. سجلات الإصدارات القديمة التي تحمل CAM هي أدلة تاريخية، ولا تمثل الاسم الحالي أو نتائج اختبارات 0.2.1.
