NASAQ 0.3.2 — Language separation

Language selector: Follow Windows (default), Arabic, English. Preference persists and applies on restart. Arabic RTL, English LTR. License key input stays LTR. Main dashboard, activation, common menus, scheduling fields, PIN actions, PDF headings and common status strings use one selected language. Scheduled event storage codes are unchanged. User filenames, playlist names and third-party voice names are preserved.

Verification: 28 functional tests per language, integrated startup/activation dialog/playback-denial smoke for Arabic and English, direction assertions and visible dashboard label checks. Screenshots and JSON are in verification/ar and verification/en. Latin format names CSV/PDF and Windows brand are allowed in Arabic.

Scope limits: not a complete translation of every inherited advanced settings dialog or third-party diagnostic. Untranslated advanced strings fall back to English. No live Keygen or signing change. Publisher configuration still absent, so unlicensed playback stays blocked. Installer clean-machine verification and complete dependency source compliance remain open as recorded in the preceding release.
