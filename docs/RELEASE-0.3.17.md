# NASAQ 0.3.17 — Ivory design and complete Arabic interface

- Refresh the player with an ivory, forest-green and sage theme, consistent controls and the approved NASAQ identity.
- Complete Arabic strings across settings, dialogs and player options; improve RTL navigation and time-column alignment.
- Display a branded vinyl record when no cover is available, with playback-aware animation in the player.
- Modernize the spectrum and distinguish the playing track from the selected track.
- Expand curated radio to 27 stations across Quran, fitness, world, classical and business listening; update Teletext’s website.
- Show unlimited radio duration and inline live-broadcast indicators. Clarify the next-adhan label according to automatic-pause settings.
- Preserve single-window file opening, duplicate prevention, adhan pause protection, silent notifications and existing activation/settings.
- Harden oversized activation-response handling and redact sensitive URL components from logs.
- Credit NASAQ developer Nawras Jarbouh and retain upstream project authors and GPL licensing.
