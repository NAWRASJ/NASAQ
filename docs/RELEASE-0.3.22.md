# NASAQ 0.3.22

- Add a prayer-screen image gallery with previews, multiple custom images and a protected bundled default. Original user files are never deleted by gallery removal.
- Unify prayer settings and add a 15-second preview that restores prior playback while respecting manual stops and activation restrictions.
- Add a daily playback toolbar with clear playback, prayer, reconnect and upcoming-event status.
- Add a guided first-run setup for language, prayer, outputs, media and playback checks.
- Save playback checkpoints and offer explicit session restoration; stopping manually clears the recovery checkpoint.
- Separate operator controls from audience preview, simplify advanced controls and add text scaling and keyboard shortcuts.
- Add a data and activation center with verified-backup information and links to existing recovery and update actions.

Validation uses automated playback and UI tests with synthetic media and silent audio output. Prayer expiry is accelerated. Physical speakers, a second monitor and recovery from an actual licensed user-session crash were not verified end-to-end. See verification.json for release results.

The unsigned x64 MSIX is for Microsoft Store submission. Store availability follows Microsoft certification. Application and codec source archives, license notices and SHA256 checksums accompany this release.
