# توقيع نسق NASAQ

نسق 0.2.1 غير موقع. لا توجد شهادة ناشر، ولم نغير حماية Windows أو نثق بشهادة ذاتية.

1. راجع المصدر والتبعيات والرخص وأكمل جرد المصادر المقابلة.
2. استخدم شهادة أو خدمة توقيع موثوقة باسم الناشر، ووقّع ملفات EXE/DLL غير الموقعة. حافظ على توقيعات الموردين الصالحة.
3. أعد بناء المثبت من الملفات الموقعة، ثم وقّع المثبت والختم الزمني وتحقق من ملفات إزالة التثبيت عند إعداد الإصدار النهائي.
4. أعد تشغيل scripts/test-package.ps1، ثم اختبارات التثبيت والترقية والإزالة والأجهزة مع حماية Windows مفعلة.

scripts/sign-release.ps1 مخصص لشهادة موجودة في مخزن المستخدم. لا ينشئ شهادة، ولا يصلح تلقائيًا لمسار SignPath Foundation، الذي يقيد توقيع مكتبات الأطراف الأخرى. تقييم الأهلية السابق يحتاج تحديث اسم المشروع وبياناته ثم مراجعة المؤسسة؛ لم نحصل على قبول.

المحاولة السابقة باسم CAM حُجبت عند ebur128.dll. لا يعني نجاح توقيع المثبت وحده قبول مكتبات التشغيل، ولا يضمن التوقيع سمعة SmartScreen فورية.
